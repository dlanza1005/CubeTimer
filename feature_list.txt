CubeTimer — Features
====================
Timer
-Press SPACE to begin inspection countdown (15s)
-Press SPACE again to start the solve timer
-Press SPACE again to stop and record the solve
-Displays last solve time when idle

Data
-solve data contains [solve_start_timestamp, solve_duration, user_comment]

Graphs:
  -Scatterplot:
    -white circles: all solves from this session
    -red line with red circles: rolling average-of-5 using WCA competition rules
    -lighter rectangles: average of 20 +/- std deviation

UI:
-click SAVE to save this session's data to data.txt and clear this session (loading previous data to be added later)
-Delete a solve by clicking its point on the points in the scatterplot (safety measures on accidental click to be added later)
-click inside the comment box to type a comment, to be associated with the next solve only.
-Hover over a scatter point to see the solve duration
-Hover over ao5/a10 to see stats
-window is resizeable and graphs re-render to fit
-DNF button to be added later
-penalty (+2) button to be added later
